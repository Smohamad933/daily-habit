# 📅 پلنر روزانه من — وب‌اپ مدیریت عادت‌ها و برنامه‌ریزی روزانه (PHP + IIS)

وب‌اپ فارسی و راست‌به‌چپ با تقویم **جلالی (شمسی)** واقعی (ماه‌های ۲۹، ۳۰ و ۳۱ روزه)، دیتابیس **SQLite** (بدون نیاز به نصب دیتابیس جدا) و موتور **هوش مصنوعی داخلی قانون‌محور**.

## ✨ امکانات

### برای کاربران
- **ثبت‌نام کامل**: نام، نام خانوادگی، موبایل، ایمیل، استان/شهر (۳۱ استان)، تاریخ تولد شمسی، مهارت‌ها
- **پلنر روزانه ساعتی**: برنامه هر ساعت از روز (مبنای ساعت بیدارشدن/خواب کاربر)
- **تقویم شمسی**: ناوبری ماهانه با طول صحیح هر ماه (۳۱/۳۰/۲۹ روز)
- **عادت‌های روزانه** با ثبت پیشرفت ۰ تا ۱۰۰٪، زنجیره روزهای پیاپی و نمودار
- **تسک‌ها**: روزانه، هفتگی و موردی با تیک انجام، ساعت و اولویت
- **هوش مصنوعی داخلی**:
  - وقتی تسکی انجام نشد، **دلیلش را می‌پرسد** (۱۰ دسته: دوستان/مهمانی، به‌تعویق‌انداختن، بی‌انگیزگی و…)
  - تسک عقب‌افتاده را **هوشمندانه در کم‌تراکم‌ترین روز هفته دوباره برنامه‌ریزی می‌کند**
  - الگوهای تکراری را شناسایی و هشدار می‌دهد
  - **گزارش ماهانه**: تیپ رفتاری، عادت‌های منفی/مثبت به درصد، تحلیل ساعت‌های ریزش، درصد رشد/پسرفت نسبت به ماه قبل + پیشنهاد اختصاصی
  - پیشنهاد بهترین ساعت آزاد برای کار جدید
- **ایجنت‌ها**: افزودن ایجنت (مربی/برنامه‌ریز/یادآور)، تحلیل لحظه‌ای و پیشنهادها — زیرساخت اتصال API خارجی در آینده آماده است
- **اهداف بازه‌ای** (هفتگی، ماهانه، سه‌ماهه، شش‌ماهه اول/دوم، یک‌ساله) با **مصاحبه استپ‌به‌استپ ایجنت**: ۵ سوال می‌پرسد و بر اساس پاسخ‌ها برنامه گام‌به‌گام با مهلت هر گام می‌سازد
- **تست شخصیت** (۴ بُعد: منظم/منعطف/اجتماعی/متمرکز) با توصیه اختصاصی و ریسک وقفه
- **نمودارها**: روند روزانه، درصد هفته‌های ماه، دونات دلایل، تحلیل ساعت‌ها (بدون هیچ کتابخانه خارجی)
- **یادداشت‌ها**، **پروفایل کامل** با ساعت بیدارشدن/خواب
- **نوتیفیکیشن سه‌لایه**: مرکز اعلان داخلی + نوتیفیکیشن مرورگر + **پوش کامل (Web Push / VAPID)** — خلاصه پایان روز (۲۱)، گزارش هفتگی (پنجشنبه) و گزارش ماهانه (آخر ماه) خودکار ارسال می‌شود
- **دارک‌مود/لایت‌مود** + حالت خودکار، کاملاً **ریسپانسیو** (موبایل/تبلت/دسکتاپ)

### پنل مدیریت

## 🚀 نصب روی IIS (گام‌به‌گام)

### ۱) پیش‌نیازها
- ویندوز سرور یا ویندوز ۱۰/۱۱ با **IIS** فعال
- نصب **PHP برای IIS** (پیشنهاد: PHP 8.1 یا ۸.۲ از [windows.php.net](https://windows.php.net/download/) — نسخه **Non Thread Safe x64**)
  - یا از Web Platform Installer استفاده کنید
- اکستنشن‌های لازم در `php.ini` فعال باشند:
  ```
  extension=pdo_sqlite
  extension=sqlite3
  extension=curl
  extension=openssl
  extension=mbstring
  extension=fileinfo
  ```
  و `extension_dir` به پوشه `ext` تنظیم شده باشد.

### ۲) تنظیم PHP در IIS
1. در IIS Manager روی سرور → **Handler Mappings** → **Add Module Mapping**:
   - Request path: `*.php`
   - Module: `FastCgiModule`
   - Executable: مسیر `php-cgi.exe` (مثلاً `C:\PHP\php-cgi.exe`)
2. **Default Document** → افزودن `index.php`

### ۳) استقرار برنامه
1. کل پوشه پروژه را مثلاً در `C:\inetpub\wwwroot\habit` کپی کنید.
2. در IIS یک **Application** یا Site جدید به این پوشه بسازید.
3. **دسترسی نوشتن**: روی پوشه `data` باید کاربرِ اپ‌پول (معمولاً `IIS_IUSRS` یا `IUSR`) دسترسی **Modify** داشته باشد:
   - راست‌کلیک روی پوشه `data` → Properties → Security → افزودن `IIS_IUSRS` با دسترسی Modify
   - (فایل دیتابیس `data/habits.db` در اولین بازدید خودکار ساخته می‌شود)
4. در مرورگر باز کنید: `http://localhost/habit/install.php`
   - اکانت مدیر ساخته می‌شود. برای دیدن نمودارها با داده نمونه، دکمه «ساخت داده دمو» را بزنید (کاربر `reza` / `Reza1387!`).
5. **فایل `install.php` را حذف کنید.**

### ۴) پوش نوتیفیکیشن (اختیاری ولی پیشنهادی)
- پوش کامل فقط روی **HTTPS** کار می‌کند. دامنه را با گواهی SSL ببندید.
- کلیدهای VAPID خودکار تولید می‌شوند؛ نیاز به تنظیم دستی نیست.

### ۵) زمان‌بند خلاصه‌ها (اختیاری)
خلاصه‌های روزانه/هفتگی/ماهانه با بازدید کاربران فعال می‌شوند. برای اجرای دقیق، در **Task Scheduler** ویندوز وظیفه‌ای بسازید که هر ۱۰ دقیقه اجرا شود:
```
curl http://localhost/habit/cron.php
```

```

├─ api.php                                 API ایجکس داخلی
├─ cron.php                                نقطه اجرای زمان‌بند
├─ admin/                                  پنل مدیریت (کاربران، محتوا، تنظیمات، خروجی اکسل)
├─ includes/                               هسته: تقویم جلالی، دیتابیس، موتور AI، پوش
├─ assets/                                 CSS و JS (بدون وابستگی خارجی)
├─ data/                                   فایل دیتابیس SQLite (ایجاد خودکار)
├─ config/config.php                       پیکربندی
└─ web.config                              تنظیمات IIS
```

## 🔒 امنیت
- رمزها با `password_hash` هش می‌شوند؛ نشست‌ها با `session_regenerate_id`
- محافظت CSRF روی همه فرم‌ها؛ کنترل مالکیت روی همه داده‌ها
- پوشه‌های `data/`، `includes/`، `config/` در `web.config` مسدود شده‌اند
- برای تولید، `display_errors` خاموش است و مقادیر حساس فقط در دیتابیس/کانفیگ نگهداری می‌شوند
